## 📁 Repository-Struktur

* `index.html` / `privacy.html`: Voll responsive HTML-Webseite der DSGVO-Datenschutzerklärung mit Dark/Light-Mode.
* `impressum.html`: Gesetzliche Anbieterkennzeichnung gemäß § 5 DDG.
* `datenschutzerklaerung.md`: Quellfassung der Datenschutzerklärung im Markdown-Format.
* `impressum.md`: Quellfassung des Impressums im Markdown-Format.
* `.nojekyll`: Verhindert die Jekyll-Verarbeitung auf GitHub Pages.

---

## 🔒 Datenschutz-Zusammenfassung (Privacy by Design)

* **Anonymer Gast-Modus:** Kein Zwang zur Angabe personenbezogener Daten.
* **Keine Werbetracker:** Keine Tracking-SDKs (kein AdMob, kein Meta Pixel).
* **EU-Serverstandort:** Supabase Backend in Frankfurt am Main (`eu-central-1`).
* **Sentry Fehlerüberwachung:** Anonymisierte Diagnosedaten mit In-App-Opt-Out.
* **Self-Service Datenlöschung:** Direkte Kontolöschung nach Art. 17 DSGVO in der App.
